#  Mobile Product Segmentation and Recommendation System

A Data Science and Machine Learning project that analyzes mobile product data, explores customer ratings and pricing patterns, segments products using K-Means clustering, and recommends similar mobile models using cosine similarity.

### Technologies Used

* Python
* Pandas, NumPy
* Plotly
* Streamlit

###  Machine Learning Techniques

* **K-Means Clustering:** Groups mobile products based on selected features.
* **Cosine Similarity:** Identifies similar mobile models for recommendations.

###  Files

* **CSV:** Processed dataset with cluster labels.
* **IPYNB:** Data preprocessing, EDA, clustering, and recommendation analysis.
* **PY:** Python application for the project.

###  Objective

To segment mobile products, analyze customer preferences, and recommend similar mobile models using machine learning.
